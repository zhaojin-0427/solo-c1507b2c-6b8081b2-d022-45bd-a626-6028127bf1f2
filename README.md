# 约束分组排演台

面向培训讲师的本地分组排练工具。Python Flask 提供本地服务，前端为原生 HTML/CSS/JavaScript，不依赖任何第三方账号或在线 API，所有数据保存在本机 `data/` 目录。

## 功能

- **学员与关系录入**：姓名 + 技能标签；支持批量导入；可定义「必须同组」「不可同组」关系。
- **分组设置**：组数、每组人数范围、标签均衡目标（选中的标签尽量均匀分布到各组）。
- **方案生成**：一次生成多个可行方案（模拟退火多种子），并列出每个方案未满足的软约束。
- **硬约束冲突定位**：冲突发生时给出相关人员与冲突链路（如 A—必须→B—必须→C，而 A 与 C 不可同组）。
- **排演台**：拖拽成员在组间移动，即时提示人数/关系违规；可锁定成员或整组后「局部重排」；支持撤销。
- **方案对比**：各组规模、标签覆盖、软约束差异一览，可一键采用任一方案。
- **本地存档**：方案（含名单、关系、设置、编排、锁定）保存到本地 JSON，可随时恢复。
- **投影/打印页**：生成匿名编号（或实名）的分组展示页，适合投影与打印。

## 运行

```bash
pip install flask
python3 app.py
```

然后浏览器打开 <http://127.0.0.1:5000>。

## 目录结构

```
app.py               Flask 应用与 API
solver.py            约束求解器（冲突检测 + 模拟退火）
templates/index.html 主页面
templates/print.html 投影/打印页
static/css/style.css 样式
static/js/app.js     前端逻辑
data/saves/          方案存档（运行时生成）
data/prints/         打印页数据（运行时生成）
```

## 硬约束与软约束

| 类型 | 内容 |
| --- | --- |
| 硬约束 | 必须同组、不可同组、每组人数范围、组数 |
| 软约束 | 各组人数均衡、指定标签在各组间均衡 |

求解器会先检测硬约束冲突（必须链与不可链矛盾、绑定块超过组上限、总人数与组容量不匹配、两两互斥单元超过组数），无冲突时才生成方案；软约束无法满足时会在方案与排演台中逐条说明。
