# 约束分组排演台

面向培训讲师的本地分组排练工具。Python Flask 提供本地服务，前端为原生 HTML/CSS/JavaScript，不依赖任何第三方账号或在线 API，所有数据保存在本机 `data/` 目录。

## 功能

- **学员与关系录入**：姓名 + 技能标签；支持批量导入；可定义「必须同组」「不可同组」关系。多轮模式下关系可设为**全程生效**或**只作用于指定轮次**。
- **分组设置**：组数、每组人数范围、标签均衡目标（选中的标签尽量均匀分布到各组）。
- **多轮轮换（2～8 轮）**：一次设置每轮独立的组数与人数范围，选择跨轮目标——
  - 任意两人同组次数上限（硬约束，超限即冲突）；
  - 尽量让每人接触更多不同同伴（同伴覆盖率最大化，可关闭）；
  - 技能标签在各轮各组保持均衡。
  - 一次生成完整轮换方案（多种子模拟退火），逐轮展示分组卡片；
  - **同伴矩阵**用色阶标出每对学员的同组轮数（0 = 未曾同组，红底 = 超上限），可点表头排序；
  - 无解时指出**冲突轮次、涉及关系与跨轮限制**（含「必须同组」强制重复超限、两轮容量鸽笼不相容等静态判定）。
- **轮换调整**：可锁定某轮成员/整组位置；拖动调整一轮后「从此轮起重排」只重排该轮及后续轮次，之前轮次冻结；应用前弹窗显示**受影响人数与重复搭档增减**，支持撤销。
- **轮换方案对比**：不同方案的同伴覆盖率、最高重复次数、超上限对数与各轮各标签分布偏差一览。
- **方案生成（单轮）**：一次生成多个可行方案（模拟退火多种子），并列出每个方案未满足的软约束。
- **硬约束冲突定位**：冲突发生时给出相关人员与冲突链路（如 A—必须→B—必须→C，而 A 与 C 不可同组）。
- **排演台**：拖拽成员在组间移动，即时提示人数/关系违规；可锁定成员或整组后「局部重排」；支持撤销。
- **角色轮值**：在已生成的单轮或多轮分组之上，为每轮每组安排主持、记录、计时、汇报等职责——
  - **角色模板**：每组名额、所需技能标签、个人禁任项、不可兼任规则（全部互斥或指定角色对）、同一人连续/累计担任上限；
  - **轮值草稿**：从当前分组方案一键建立；按组角色槽拖放安排，成员×轮次矩阵总览；来源分组变化时草稿只标为**过期**，不改写已确认版本；
  - **锁定与补齐**：讲师锁定已安排角色后由系统补齐空缺（模拟退火多种子），候选按**空缺数、资格违规、角色重复、负担差异**对比后采用；
  - **即时校验**：拖动后即时指出一人同轮兼任、角色无人、资格不符及锁定冲突，点选提示可定位成员和轮次；
  - **确认版本**：确认后冻结来源分组与规则，生成逐轮角色卡与匿名打印页；版本只读，只有复制成新草稿才能调整；角色方案随本地存档保存，旧存档仍可正常加载。
- **方案对比**：各组规模、标签覆盖、软约束差异一览，可一键采用任一方案。
- **本地存档**：方案（含名单、关系及生效轮次、单/多轮设置、全部方案、当前编排与各轮锁定）保存到本地 JSON，可随时恢复。
- **投影/打印页**：单轮生成匿名编号（或实名）分组展示页；多轮轮换生成**按轮分页**视图（方向键/按钮翻页，打印时每轮一页），适合投影与打印。

## 运行

```bash
pip install flask
python3 app.py
```

然后浏览器打开 <http://127.0.0.1:5000>。

## 硬约束与软约束

| 类型 | 内容 |
| --- | --- |
| 硬约束 | 必须同组、不可同组、每组人数范围、组数 |
| 软约束 | 各组人数均衡、指定标签在各组间均衡 |

求解器会先检测硬约束冲突（必须链与不可链矛盾、绑定块超过组上限、总人数与组容量不匹配、两两互斥单元超过组数、**不可同组关系图不可 k 着色**——如 2 组时的奇环），无冲突时才生成方案；软约束无法满足时会在方案与排演台中逐条说明。

**无解判定**：系统只输出满足全部硬约束的方案。启发式搜索找不到可行解时，会再做一次精确回溯判定：确认无解则返回冲突说明（涉及人员 + 冲突链路），确认有解则返回该可行方案——不会展示 `hardOk=False` 的不可行方案。

**锁定语义**：成员锁与整组锁在局部重排中绝不会被移动。若锁定状态自相矛盾（如同一“必须同组”连通块的成员被分别锁定在不同组、锁定成员间存在“不可同组”、锁定组人数越界），局部重排会拒绝执行并在排演台显示冲突人员与关系链。

## 多轮轮换

| 类型 | 内容 |
| --- | --- |
| 硬约束 | 每轮各自的组数/人数范围、按轮次作用域生效的必须/不可同组关系、任意两人同组次数上限（cap） |
| 软目标 | 同伴覆盖率最大化、技能标签在各轮各组均衡、各组人数均衡 |

- **关系作用域**：每条关系可选「全程生效」或勾选只作用于某几轮；求解时按轮过滤。
- **跨轮上限的静态判定**：除「必须同组」使两人被迫同组超过 cap 外，还做两轮容量鸽笼判定——第 j 轮一组至少 `min_j` 人放进第 i 轮 `g_i` 个组，必有至少 `⌈min_j/g_i⌉` 人在第 i 轮同组；若该数大于 cap，则该配置数学上不可行，生成前即报错并指明涉及的两轮，而不是搜索后才失败。
- **只重排后续轮次**：从第 k 轮起重排时，1～k-1 轮逐组冻结；第 k 轮的成员锁/整组锁保持不动。后端先校验冻结轮编排是否仍合法（人数/关系），再对第 k 轮起做退火；返回受影响人数与「同组次数增加/减少」的搭档对供前端预览，应用后可撤销。
- 同伴矩阵、覆盖率、最高重复次数与各轮标签偏差均在前端按**当前编排实时重算**（包括手动拖动后），不依赖生成时的快照。

## 角色轮值

| 类型 | 内容 |
| --- | --- |
| 硬约束 | 锁定安排不动、个人禁任、不可兼任规则、成员须在本组 |
| 软目标 | 空缺最少、资格（所需标签）满足、连续/累计上限、角色轮换（少重复）、负担均衡 |

- **草稿与来源**：草稿记录建立时的来源分组指纹；排演台中任何分组变动（重新生成、拖动、重排、恢复存档）只会把草稿标为**过期**，草稿自身与已确认版本均不被改写。
- **锁定语义**：锁定以「轮次 × 组 × 角色 × 成员」为单位。锁定成员不在组、被禁任、锁定间互斥或超额时，补齐会被拒绝并逐条说明。
- **候选比较**：补齐返回多个候选，按空缺数 → 资格违规 → 同轮兼任 → 超限 → 角色重复 → 负担差异排序，表格中逐项对比后采用。
- **版本冻结**：确认版本时把当时的模板、来源分组、安排与名单快照一并冻结；版本只读，可查看逐轮角色卡、匿名打印，或**复制为新草稿**继续调整。
- **存档兼容**：角色模板、草稿与全部版本随 `data/saves/` 存档保存；无角色数据的旧存档加载时角色区保持空状态，不受影响。

## 回归测试

```bash
# API 级回归（无需启动服务，使用 Flask test_client）
python3 tests/test_regression_api.py

# 真实前后端 E2E（jsdom 驱动真实页面 + 真实 Flask 服务）
python3 app.py &                # 先启动服务
npm install jsdom               # 首次需要
node tests/e2e_jsdom.js
```

覆盖场景：奇环无解判定与冲突链展示、偶环对照可解、分裂锁定（成员锁/整组锁/混合）报冲突、合法锁定在重排后保持不动、正常多方案生成、尺寸打包无解的精确判定；多轮轮换的完整生成（覆盖率/上限/关系作用域）、跨轮容量与强制重复的静态冲突、锁定后只重排后续轮次且冻结轮/锁定保持、轮换存档往返与按轮分页打印、单轮无解空状态、拖动后硬约束与标签偏差实时重算；角色轮值的空缺补齐与候选指标、锁定保持/连续与累计上限/禁任/锁定冲突阻断、角色存档往返（含旧存档兼容）与匿名打印页，以及前端全流程（模板→草稿→拖放校验→补齐→确认→过期→复制→存档恢复）。
